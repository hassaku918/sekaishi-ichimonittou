# 世界史一問一答（自習用）

Memora X 世界史一問一答（com.ichinari.sekaishi）の学習フローを参考に、
個人の自習用として再構成した Android アプリ。

## 方針（本家からの変更点）
- 課金・会員ステージ（プライム／プラチナ／プラチナMAX）・広告はなし。全機能を最初から使える。
- my単語帳は複数作成できる（名前変更・削除・単語帳単位の学習に対応）。
- 収録問題は、共通テスト・早慶・MARCH の頻出用語範囲に寄せて独自に作成したもの。
  本家の問題文・解説の複写はしていない。

## 収録問題
- 一問一答 4,350問（22章立て、難易度3段階、年号付き2,543問）
- 章: 古代オリエントと地中海世界／ギリシア・ローマ／アジアの古代帝国／インド史／
  東南アジア史／中国史／イスラーム世界の形成と拡大／ヨーロッパ中世／
  大航海時代と近世ヨーロッパ／市民革命と産業革命／国民国家の形成と帝国主義／
  中国近世・近代／インド・東南アジア近世・近代／アメリカ史／アフリカ史／
  中央アジア史／ラテンアメリカ史／日本と世界／文化史／二つの世界大戦／
  冷戦と脱植民地化／現代世界

## 機能
- 一問一答と年号モード（論述モードは搭載していない）
- ヨコ（単元順）・タテ（地域別）の切り口
- スワイプ判定（右＝分かる／左＝分からない／下＝まあまあ）とボタン判定
- 忘却曲線ベースの復習: 間隔 [0,1,2,4,7,14,30] 日、間違えると間隔リセット、
  5回連続正解で卒業。モードは「すべて・暗記・ニガテのみ・未学習」
- 学習カレンダー（直近35日）と連続記録（1日10問で継続）
- 学習データの書き出し・読み込み（JSON共有／貼り付け）、リセット

## ビルド
GitHub Actions（Build Release APK）で署名付きリリース版 `app-release.apk` をビルドし、
Releases の `apk-latest` タグと artifact から取得する。
署名は `app/signing/sekaishi.jks` の固定鍵に統一しているため、以後は上書きインストールで更新できる
（v0.1.0 のデバッグ署名版からは署名が異なるため、一度だけ入れ替えが必要）。

## v0.6.0 の変更
- 学習画面の答え表示を本家の実機動画をフレーム単位で確認して作り直し
  - タップでは絶対に答えが出ない。スワイプして一定距離を動かすと答えの場面に移る（離しても答えは残る）
  - 方向オーバーレイはカードの上に表示（従来はカードの背面だった）
  - 判定時はカードがその方向へ飛び出し、背景に判定色が広がる（本家の演出）
  - 離した位置が浅ければカードはアニメーションで元の位置に戻る
  - 「こたえ」ラベルを区切り線の中央に配置。目隠し（かくす）／しおりのボタンは常時表示に

## v0.5.0 の変更
- ダークモードを追加（ダークブルー基調）。設定画面の「テーマ」で ライト／ダーク を切替、選択は保存される
  - パレットをテーマ連動化し、全画面（ホーム・学習・カレンダー・単語帳・設定）が追随する
- ホームの設定ボタンを歯車の絵文字（⚙️）に変更
- 学習画面の答え表示を本家の動きに変更: タップでは出ず、スワイプして一定距離を動かすと
  カードの中で問題文が薄くなり答えへ遷移（フェード＋スライド＋サイズ変化）する。そのまま離すと判定

## v0.4.0 の変更
- 本家の実機画面（ライトテーマ）に合わせて全面再構成（v0.3.0 の黒テーマはストア宣伝画像側だったため差し替え）
  - ホーム: ドット柄の淡背景＋白カード。ヘッダーボタン（連続記録／カレンダー／設定）、
    連続記録カード、苦手の聞き流しカード（タップでニガテ問題のセッション開始）、
    選択範囲の進捗カード（タイトル・習得率・着手数・正解の連ピル、タップで期限切れ復習）
  - 範囲は2階層化: ヨコは時代グループ（色付き横スクロールピル）→単元チップ、
    タテは地域ピル→その地域の単元チップ、年号はグループのみ
  - 出題軸・モードは青選択のセグメント、レベルピルはグループ色で表示
  - 学習画面: ドラッグ開始で答えを表示し、右＝合っていた（緑）／左＝間違っていた（グレー）／
    下＝まあまあ（青）の全画面オーバーレイで判定。判定ボタンは廃止しスワイプのみに
  - カード上部に状態ピル（新規／N連続正解／前回不正解）＋正誤ドット＋回数、
    左下にレベル名（Lv1 共通テスト向け基礎／Lv2 私大向け応用／Lv3 早慶向け難題）
  - ヘッダーに「もどす」ボタンを追加（最後の判定を取り消し）

## v0.3.0 の変更
- UIを本家 Memora X の実画面（ストア掲載スクリーンショット）に合わせて再構成
  - ホームは黒テーマ化。下部ナビを廃し、ヘッダーの連続記録／カレンダー／設定ボタンに集約
  - 連続記録カード（今日のログインプレイ＋進捗バー）、全体の進捗カード（習得率・着手数・正解の連ピル）
  - 出題軸はセグメント切替（ヨコ／タテ／年号／my単語帳）、範囲はチップ選択（ヨコ=赤、タテ=紫）、
    モードもセグメント切替（すべて／暗記／ニガテのみ／未学習）、レベルは Lv1〜Lv3 のトグルピル
  - 開始ボタンに絞り込み後の問題数を表示。セッションは上限30問を撤廃し範囲の全問を出題
  - 学習画面は本家同様の白カード化: 上部に進捗バーと残数、カード上部に連続正解ピル＋正誤ドット＋回数、
    解答表示後は問題文がグレーになり「こたえ」区切りの下に答えを大きく表示。
    判定ボタンは 自信なし（グレー）／まあまあ（青）／自信アリ（緑）
  - カレンダーは本家同様、総問題数の大きな表示＋タブ（総問題数／覚えた問題／苦手な問題）＋
    日ごとのリング表示（1日100問を満量）に変更

## データの追加
`app/src/main/assets/questions_*.json` に問題を追加する（起動時に自動で読み込む）。
形式: {"id","chapter","region","level","q","a","year","note"}
